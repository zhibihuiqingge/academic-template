# 提交前学术诚信与可复现性审计

这是可复用的待填写清单，不是已经通过的审计报告。每次提交针对实际稿件版本填写，保留证据与失败记录。

- 课程、论文及稿件路径：待确认
- 稿件版本或提交 SHA：待确认
- 审计人、日期及检查环境：待确认
- 教师原始要求与课程配置版本：待确认
- 适用期刊指南及版本：待确认
- 总体结论：待检查（必要证据不齐不得填“通过”或“可提交”）

状态使用“待检查 / 通过 / 失败 / 无法执行 / 不适用”；后两者必须说明原因，未运行不得算通过。存在待检查、失败或无法执行的必需项时，先解决或明确披露，不能自动视为完成。不适用须依据实际方法与教师要求判断。

| 必查项 | 检查方法与所需证据 | 状态 | 证据路径、问题及后续动作 |
| --- | --- | --- | --- |
| 1. 文献真实存在 | 对照出版商、期刊、Crossref、DOI 注册记录或可靠数据库；未能独立核验者标“未核实” | 待检查 | 待填写 |
| 2. 书目元数据准确 | 逐项核对作者、题名、年份、出版物、卷期页、DOI/URL；记录冲突 | 待检查 | 待填写 |
| 3. 引用支持论点 | 对照实际查阅原始段落、上下文和适用条件，关联正文位置 | 待检查 | 待填写 |
| 4. 引文与页码准确 | 逐字核对原文及实际页码，区分 PDF 页序和印刷页码；无页码时使用真实定位方式 | 待检查 | 待填写 |
| 5. 数学推导有效 | 假设、变量、定义域、必要步骤、必要/充分条件；博弈模型含最佳反应、可行性和边界检验 | 待检查 | 待填写 |
| 6. 数值计算正确 | 核对公式、参数、单位、精度、算法及适用的独立计算或基准 | 待检查 | 待填写 |
| 7. 结果可复现 | 从已记录输入执行脚本，记录命令、依赖、版本、种子和输出对照；说明容差与非确定性 | 待检查 | 待填写 |
| 8. 教师要求符合 | 按原始任务书和评分标准逐条对应正文、字数、方法、产物及 AI 使用与披露规则 | 待检查 | 待填写 |
| 9. 期刊格式符合 | 如有要求，对照已确认官方指南检查摘要、关键词、标题、图表、引用与文件格式 | 待检查 | 待填写 |
| 10. 未解决问题披露 | 汇总所有未核实来源、未验证步骤、数据访问限制、失败检查与结论影响 | 待检查 | 待填写 |

## 核验摘要（实际检查后填写）

- 已完成检查及证据：待填写
- 失败检查与诊断：待填写
- 未运行、跳过或无法执行的检查及原因：待填写
- 未解决事项、结论影响、责任人及下一步：待填写
- 人工复核范围与意见：待填写

脚本可辅助检查引用键完整性、重复项、计算和文件路径；来源是否真正支持论点、引文上下文、证明是否完整、数据是否合规、教师要求是否正确解释仍需实质阅读和人工判断。联网失败不等于来源不存在；格式检查成功不等于学术审计通过。
