# 文献、证据与核验记录

保存有权共享的文献笔记、证据表、BibTeX/CSL JSON 导出与核验记录。Zotero 可作为外部主库，项目仅保留需要的导出和对应关系，不提交 Zotero 数据库、凭据或本机绝对附件路径。

建议为每条实际使用文献记录以下字段，开始有真实材料后再建立记录，不填虚构示例：

- BibTeX 引用键、Zotero item key（若有）、DOI 或其他稳定标识。
- 作者、标题、年份、出版物及卷期页等实际元数据。
- 核验来源 URL 或记录标识、核验日期、已核对字段、冲突与状态；无法独立核验标“未核实”。
- 全文访问状态、实际查阅章节或页码（区分 PDF 页序与印刷页码）。
- 正文论点位置、支持论点的原文位置、证据边界及尚未解决的问题。

代理应优先对照出版商、期刊、Crossref、DOI 注册记录和可靠数据库。元数据核验不等于读过全文；不得编造引文、页码或结论。导入前按 DOI 等标识及实际元数据去重，稳定引用键，核对正文与根目录 `references.bib` 的对应。改变引用键时同步正文并记录原因；解析成功不代表真实性或支持关系已核实。
